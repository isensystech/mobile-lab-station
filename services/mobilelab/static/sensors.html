How to read this page

Live A sensor sends readings now. Manual A person reads the instrument and types the number. It works, even on a day with no reading. Planned Not fitted. It shows no number.

A planned sensor never shows a value, not even an example. A number beside a sensor that does not exist would be a lie that outlives the demo.

GPS status

GPS OK needs a 3D fix on four satellites. A 3D fix finds four unknown values, so it needs four satellites.

Indoors the receiver finds satellites. It does not get a fix. Then the status shows NO FIX. Carry the station outside to get a fix.
