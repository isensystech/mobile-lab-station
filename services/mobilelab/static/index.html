Where these numbers come from

LineMeasurementSourceReal?Drawn

Simulated data. Not a measurement.

A generator made these numbers. Do not use them as evidence about any real place.

A line drawn with dashes is not real. A line drawn solid is a measurement.

A line drawn in steps is a cell average. The number covers a whole area for a whole hour. It is not a reading from one place.

Stop the station?

Shut down first, then unplug. Pulling the plug while it runs can damage the stored data.

GPS status

GPS OK needs a 3D fix on four satellites. A 3D fix finds four unknown values, so it needs four satellites.

Indoors the receiver finds satellites. It does not get a fix. Then the status shows NO FIX. Carry the station outside to get a fix.
